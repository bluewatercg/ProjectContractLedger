# 数据监控和提醒功能使用指南

## 功能概述

数据监控和提醒功能为ProjectContractLedger系统添加了主动的业务流程监控能力，帮助用户及时处理重要的业务事项，避免遗漏关键节点。

## 🎯 核心功能

### 1. 合同类型管理

#### 合同续签设置
- **是否续签**: 勾选框，标识该合同是否需要续签
  - ✅ 勾选：该合同需要定期续签（如运维服务、年度维护等）
  - ❌ 不勾选：该合同为一次性合同（如项目开发、技术咨询等）
- **提醒天数**: 当勾选"是否续签"后，可选择提醒时间
  - **5天**: 合同到期前5天提醒
  - **30天**: 合同到期前30天提醒（默认）
  - **60天**: 合同到期前60天提醒

#### 使用方法
1. 在创建或编辑合同时，根据合同性质勾选"是否续签"
2. 如果勾选了续签，选择合适的提醒天数（5天、30天、60天）
3. 系统会根据设置在合适的时间提供续签或到期提醒

### 2. 首页提醒区域

#### 提醒类型
- **🔄 合同续签提醒**: 续签合同即将到期，需要联系客户安排续签
- **⏰ 合同到期提醒**: 一次性合同即将到期，需要确认项目完成情况
- **📄 开票提醒**: 合同已生效但尚未开具发票
- **💰 收款提醒**: 发票已开具但尚未收到款项

#### 优先级说明
- **🔴 高优先级**: 紧急事项，需要立即处理
- **🟡 中优先级**: 重要事项，建议尽快处理  
- **🟢 低优先级**: 一般事项，可适当安排处理

#### 操作方式
- **处理**: 点击直接跳转到相关业务页面进行处理
- **忽略**: 标记该提醒为已处理，不再显示
- **点击项目**: 查看详细信息

## 📋 使用步骤

### 步骤1：数据库初始化

```sql
-- 执行数据库迁移文件
source database/migrations/add_contract_type_and_reminder_fields.sql
```

### 步骤2：设置合同类型

1. 进入合同管理页面
2. 编辑现有合同或创建新合同
3. 在合同类型字段中选择：
   - **一次性合同**: 适用于项目开发、技术实施等
   - **续签合同**: 适用于运维服务、年度维护等
4. 对于续签合同，设置合适的续签提醒天数

### 步骤3：使用提醒功能

1. **查看提醒**: 登录系统后，在Dashboard首页查看待处理事项
2. **处理提醒**: 点击"处理"按钮跳转到相关页面
3. **忽略提醒**: 对于不需要处理的项目，点击"忽略"按钮
4. **刷新数据**: 点击刷新按钮获取最新的提醒信息

## 🔍 业务场景示例

```
是否续签：✗ （不勾选）
提醒逻辑：
- 合同生效 → 开票提醒
```

```
是否续签：✓ （勾选）
提醒天数：30天
提醒逻辑：
- 合同生效 → 开票提醒
- 发票开具 → 收款提醒
- 到期前30天 → 续签提醒
```

### 场景3：咨询服务项目
```
是否续签：✗ （不勾选）
提醒逻辑：
- 合同签署后7天内无发票 → 中优先级开票提醒
- 发票开具后30天内无收款 → 中优先级收款提醒
- 合同到期前15天 → 项目交付确认提醒
```

## ⚙️ 配置说明

### 提醒时机配置

#### 合同续签提醒
- 默认提前30天提醒
- 可在合同编辑页面自定义天数（1-365天）
- 距离到期7天内显示为高优先级

#### 开票提醒
- 合同生效后立即触发
- 7天内显示为低优先级
- 30天以上显示为高优先级

#### 收款提醒
- 发票开具后立即触发
- 30天内显示为中优先级
- 60天以上显示为高优先级

### 自动更新机制
- 提醒数据每次页面加载时自动更新
- 支持手动刷新获取最新状态
- 处理后的提醒会自动从列表中移除

## 🚀 最佳实践

### 1. 合同续签设置建议
- **技术开发、项目实施**: 不勾选"是否续签"
- **运维服务、技术支持**: 勾选"是否续签"，选择30天或60天提醒
- **年度服务、长期合作**: 勾选"是否续签"，选择60天提醒
- **短期项目、紧急任务**: 不勾选"是否续签"

### 2. 日常使用建议
- **每日检查**: 登录系统后优先查看Dashboard提醒区域
- **优先处理**: 按照优先级（高→中→低）顺序处理提醒事项
- **及时更新**: 处理完成后及时更新相关状态或标记为已处理

### 3. 团队协作建议
- **分工明确**: 不同类型的提醒指定专人负责
- **定期回顾**: 定期检查被忽略的提醒是否需要重新处理
- **流程优化**: 根据提醒频率优化业务流程

## 🔧 故障排除

### 常见问题

#### Q: 提醒区域显示为空或加载失败
**解决方案:**
1. 检查网络连接是否正常
2. 点击刷新按钮重新加载数据
3. 检查浏览器控制台是否有错误信息

#### Q: 合同类型选项不显示
**解决方案:**
1. 确认数据库迁移文件已正确执行
2. 检查后端服务是否正常运行
3. 清除浏览器缓存后重新加载

#### Q: 提醒优先级显示不正确
**解决方案:**
1. 检查合同和发票的日期设置是否正确
2. 确认当前系统时间是否准确
3. 核实业务逻辑是否符合预期

#### Q: 点击处理按钮无反应
**解决方案:**
1. 检查目标页面路由是否配置正确
2. 确认用户是否有相应的访问权限
3. 查看浏览器控制台的错误信息
