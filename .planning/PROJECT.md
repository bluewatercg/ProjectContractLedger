# ProjectContractLedger - 业务分类与统计分析模块

## What This Is

为现有企业合同管理系统增加**业务类型多层级分类**和**统计分析**功能，让2人团队（身兼管理、运营、财务多职）能够按业务类型维度快速了解业务结构、分析合同表现、进行财务对账和收入分析。

## Core Value

让管理者通过业务类型分类，一眼看清各业务线的合同数量、金额、回款情况，快速定位问题业务或高潜力业务。

## Requirements

### Validated

现有系统已具备的能力：

- ✓ 多租户系统（Kit套账隔离） — existing
- ✓ 合同全生命周期管理（客户、合同、发票、支付、对账） — existing
- ✓ Midway.js + Vue 3 + Element Plus 技术栈 — existing
- ✓ JWT认证和多租户访问控制 — existing
- ✓ 基础Dashboard统计（合同金额、回款金额） — existing
- ✓ Excel/PDF导出能力（exceljs 4.4.0, pdfkit 0.17.2） — existing
- ✓ 图表可视化能力（echarts 5.4.0） — existing
- ✓ TypeORM数据库ORM — existing

### Out of Scope

明确不在本期范围：

- 复杂的权限隔离（2人团队，所有功能对所有人可见） — 团队规模小，不需要细粒度权限
- 实时自动刷新统计（手动刷新即可） — 避免性能压力，按需刷新
- 业务类型的历史版本管理 — 首期聚焦核心功能
- 跨Kit业务类型共享 — 每个Kit独立维护业务类型
- 自动化分类规则（AI/规则引擎） — 手动分类更灵活可控
- 移动端专门优化 — Web响应式即可满足需求

## Context

**现有系统背景：**
- 已运行的企业合同管理系统，有完整的合同、客户、发票、支付、对账功能
- 使用多租户架构（Kit套账），支持数据隔离
- 2人团队使用，需求简单直接，不需要复杂的流程和权限

**业务背景：**
- 公司有多条业务线：定制化开发、运维服务（角膜类、融资租赁类）、软件销售等
- 管理层需要快速了解各业务线的合同表现
- 运营需要按业务类型分析合同趋势
- 财务需要按业务类型做对账和收入分析
- 历史合同已有一定积累，需要补充分类后才能统计分析

**技术背景：**
- 已有echarts用于图表，exceljs/pdfkit用于导出
- Vue 3 + Element Plus前端，Midway.js后端
- TypeORM数据库ORM，MySQL 8.0数据库

## Constraints

- **技术栈**: 必须基于现有Midway.js + Vue 3 + Element Plus技术栈，不引入新框架 — 保持技术一致性
- **多租户**: 所有新功能必须支持Kit多租户隔离 — 系统架构约束
- **性能**: 统计分析手动刷新，避免自动实时计算带来的性能压力 — 2人使用，按需刷新足够
- **用户规模**: 2人团队，所有功能对所有人开放，不需要复杂权限系统 — 简化实现复杂度
- **数据库**: 使用MySQL 8.0，通过TypeORM操作 — 现有基础设施
- **前端库**: 使用echarts 5.4.0做图表，Element Plus做UI — 已有依赖

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| 业务类型采用灵活多层级树形结构 | 支持未来业务扩展，不同业务可能有不同层级需求 | — Pending |
| 所有人可配置业务类型 | 2人团队，都是管理者，简化权限控制 | — Pending |
| 统计数据手动刷新 | 避免实时计算性能压力，2人使用按需刷新足够 | — Pending |
| Dashboard概览 + 独立分析页 | 快速查看 + 深度分析两种场景都满足 | — Pending |
| 支持批量设置历史合同业务类型 | 历史数据需要补充分类才能统计分析 | — Pending |
