# Requirements: ProjectContractLedger - 业务分类与统计分析

**Defined:** 2026-02-06
**Core Value:** 让管理者通过业务类型分类，一眼看清各业务线的合同数量、金额、回款情况，快速定位问题业务或高潜力业务

## v1 Requirements

### 业务类型分类管理 (Category Management)

- [ ] **CAT-01**: 用户可以创建多层级业务类型（支持N层树形结构）
- [ ] **CAT-02**: 用户可以编辑业务类型名称和层级关系
- [ ] **CAT-03**: 用户可以删除业务类型（需要检查关联合同数量并提示）
- [ ] **CAT-04**: 用户可以拖拽调整业务类型的排序和层级
- [ ] **CAT-05**: 用户可以查看业务类型树形列表
- [ ] **CAT-06**: 用户在合同录入/编辑时可以选择业务类型（级联选择器）
- [ ] **CAT-07**: 用户可以批量设置多个合同的业务类型（支持筛选条件）
- [ ] **CAT-08**: 业务类型支持启用/禁用状态（禁用后不可选择，但已关联合同保留）

### Dashboard统计卡片 (Dashboard Stats)

- [ ] **DASH-01**: Dashboard显示"按业务类型统计"卡片
- [ ] **DASH-02**: 卡片显示业务类型占比饼图（按合同金额）
- [ ] **DASH-03**: 卡片显示前5个业务类型快速摘要
- [ ] **DASH-04**: 点击卡片跳转到业务分析详细页

### 业务分析页面 (Business Analysis Page)

- [ ] **ANALYSIS-01**: 新增"业务分析"菜单项（独立页面）
- [ ] **ANALYSIS-02**: 支持时间范围选择（年度/月度/季度/自定义日期）
- [ ] **ANALYSIS-03**: 支持业务类型多选筛选（树形选择器，支持父子联动）
- [ ] **ANALYSIS-04**: 页面顶部显示统计概览数字（合同数、总金额、回款率等）
- [ ] **ANALYSIS-05**: 提供"刷新数据"按钮手动触发统计计算

### 统计维度 (Statistics Dimensions)

- [ ] **STAT-01**: 按业务类型统计合同数量
- [ ] **STAT-02**: 按业务类型统计合同总金额
- [ ] **STAT-03**: 按业务类型统计回款金额
- [ ] **STAT-04**: 按业务类型统计发票金额
- [ ] **STAT-05**: 按业务类型统计未回款金额（合同金额 - 回款金额）
- [ ] **STAT-06**: 计算回款率（回款金额 / 合同金额 * 100%）

### 可视化图表 (Visualization Charts)

- [ ] **VIS-01**: 饼图展示业务类型占比（可选维度：金额/数量/回款）
- [ ] **VIS-02**: 柱状图展示不同业务类型对比（横向或纵向）
- [ ] **VIS-03**: 折线图展示业务类型时间趋势（按月度/季度）
- [ ] **VIS-04**: 明细数据表格（可排序，可展开查看子类数据）
- [ ] **VIS-05**: 图表支持点击交互（点击图表元素查看明细）
- [ ] **VIS-06**: 多层级业务类型支持下钻查看（父类展开查看子类数据）

### 报表导出 (Report Export)

- [ ] **EXPORT-01**: 导出业务分析Excel报表（包含图表和明细数据）
- [ ] **EXPORT-02**: 生成业务分析PDF报告（包含图表和汇总数据）
- [ ] **EXPORT-03**: 导出文件名包含时间范围和导出时间

## v2 Requirements

可能在后续版本考虑的功能：

### 高级分析

- **ADV-01**: 业务类型同比环比分析
- **ADV-02**: 业务类型预测趋势（基于历史数据）
- **ADV-03**: 业务类型关联客户分析（哪些客户属于哪些业务类型）
- **ADV-04**: 业务类型盈利能力分析（考虑成本）

### 自动化

- **AUTO-01**: 根据合同关键字自动推荐业务类型
- **AUTO-02**: 定时生成业务分析报告（每月自动发送）
- **AUTO-03**: 业务类型异常告警（回款率低于阈值）

### 协作

- **COLLAB-01**: 业务分析报告分享链接
- **COLLAB-02**: 业务分析报告评论和批注

## Out of Scope

明确不在范围内的功能：

| Feature | Reason |
|---------|--------|
| 细粒度权限控制 | 2人团队，所有功能对所有人可见，不需要复杂权限 |
| 实时自动刷新统计 | 手动刷新按钮即可，避免性能压力 |
| 业务类型历史版本管理 | 首期聚焦核心功能，历史版本管理复杂度高 |
| 跨Kit业务类型共享 | 每个Kit独立维护业务类型，符合多租户隔离原则 |
| 自动分类规则引擎 | 手动分类更灵活可控，AI分类可能不准确 |
| 移动端原生App | Web响应式设计即可满足需求 |
| 业务类型预算管理 | 超出统计分析范围，属于预算管理模块 |
